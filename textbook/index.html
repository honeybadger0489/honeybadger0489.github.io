Agentic Engineering

One Living Textbook. Three grains of the same practice.

PartGrainQuestion it answers
Part 1 — Unit (Loops)Repeated work until a stop conditionWhat runs again, and when does it stop?
Part 2 — Wrapper (Harness)Model + rules, skills, hooks, isolationWhat wraps the model so it can act safely and repeatedly?
Part 3 — System (Factory)Agents + code + gates + sandboxesHow does a whole system produce reliable work?

This structure follows Stage 3 multi-source debate: Austin emphasizes the loop unit; Cole emphasizes the harness wrapper; Indy emphasizes the factory system. Stage 3 keeps those fights unmerged. This book teaches the scale stack without forcing a false consensus.

What this book is

  • Stage 4 teaching synthesis from Validated Knowledge Clusters only
  • Citation-first: every major claim points at Stage 3 status + persons
  • Course-ready: chapters are module-sized; checklists are lab-sized; contests are exam-sized

What this book is not

  • Not a second Source Graph or Enrichment pass
  • Not auto-resolved truth (see contests)
  • Not a Wealth package, not live money, not Hermes/Telegram/Discord as command
  • Not quizzes, certificates, or app UI (downstream of this book)

How to read (human)

  1. glossary — lock vocabulary before Part 1
  2. Part 1 → Part 2 → Part 3 in order (unit → wrapper → system)
  3. contests when a chapter flags disagreement
  4. sources when you need provenance for a claim
  5. status for signoff debt and course-readiness

How to read (agent)

Prefer: status.md → active part chapter → contests.md for the same topic → sources.md for cluster path. Do not invent spoken lecture. Do not clear human flags.

Shared modules (used by all parts)

  • shared/agent-skills-module — official SKILL.md specialization (cluster score 82, clean)
  • shared/verification-module — verifiability, cost-of-error, plan→execute→verify

Forward path to courses

See course-hooks for planned module / quiz / lab / exam derivation rules. No course content is generated in v0.1 beyond hooks.
